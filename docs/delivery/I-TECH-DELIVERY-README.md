# I-TECH - muaman store - Windows Delivery

## Product Name

I-TECH (muaman store)

## Installer Filename

`I-TECH-Setup.exe`

## Supported Platform

Windows 10/11 (x64 only)

## Installation Steps

1. Copy `I-TECH-Setup.exe` to your computer.
2. Double-click the file to begin installation.
3. Follow the on-screen instructions.
4. The program installs to your user folder without requiring administrator privileges.

## First-Run Steps

1. After installation, open the Start Menu and search for "I-TECH".
2. On first launch, the setup screen will appear.
3. Create the owner account (you will set a username and password).
4. Configure your shop identity (name, logo, address, phone).
5. You are ready to use the application.

## Shop Identity / Configuration

From the Settings screen (owner only), you can configure:

- Shop name
- Shop logo
- Address
- Support phone number
- Brand color
- Invoice title and footer
- Thermal printer settings

## Licensing

The application requires activation for business write operations. Read operations and navigation remain available without activation. If activation is needed, use the activation settings within the application.

## Backup Recommendation

Regular backups are strongly recommended. Use the built-in backup feature (Settings > Backup). Backups create a copy of your database file that can be restored if needed.

## Restore Warning

The restore feature will replace your current database with the backup. A safety backup is automatically created before any restore operation. Always verify the backup file before restoring.

## Data Storage

Application data is stored locally on your computer. The database file is located in the standard databases directory for your platform.

## Uninstall / Update

To uninstall: Open Windows Settings > Apps > Installed apps > search for "I-TECH" > click Uninstall. Alternatively, right-click "I-TECH" in the Start Menu and select Uninstall.

**Important:** Uninstalling removes the program but does NOT delete your business data. The database file remains on your computer and will be used if you reinstall.

To update: Install the new version over the existing installation. Your data will be preserved.

## Support

Configure the support phone number in Settings to appear on printed invoices. For technical support, contact I-TECH.
