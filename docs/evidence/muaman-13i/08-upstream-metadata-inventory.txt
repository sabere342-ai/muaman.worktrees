MUAMAN-13I UPSTREAM SDK INTERNAL METADATA INVENTORY
====================================================
Captured (UTC): 2026-08-04 19:07:30
The official Flutter Windows SDK archive ships internal upstream metadata.
This inventory documents their existence and high-level content. They are
Flutter SDK toolchain metadata, NOT application-source Git metadata. They
came directly from the pristine official archive and were not removed.

1) .git/  (present in both pristine SDK A and SDK B)
   Type: git repository of the upstream Flutter framework distribution.
   HEAD: "ref: refs/heads/stable"
   Contents: hooks/, info/, logs/, objects/, refs/, config, description,
             HEAD, index, ORIG_HEAD, packed-refs
   Size (SDK A): 131.43 MB across 1,009 files (typical for a shipped
             shallow/clone history). This is upstream-owned metadata.
   Classification: upstream Flutter SDK metadata - NOT application source
             metadata. The MUAMAN-13G "Git-free" claim applies to the
             application source archive (the app/ subtree), not to the
             Flutter distribution. This report keeps that distinction
             explicit. It is never rewritten, repacked, or removed by the
             MUAMAN-13I verification process.

2) .pub-preload-cache/  (present in both pristine SDK A and SDK B)
   Type: pre-loaded Dart package archive cache shipped by the Flutter
         distribution for offline pub resolution.
   Contents: 167 entries, all <package>-<version>.tar.gz files
             (e.g. analyzer-6.7.0.tar.gz, flutter_lints-4.0.0.tar.gz,
             intl-0.19.0.tar.gz, win32-5.5.1.tar.gz).
   Size (SDK A): 191.44 MB.
   Classification: upstream Flutter SDK cache artifact - pre-shipped,
             not generated by MUAMAN-13I and not application metadata.

Distinction maintained throughout this phase:
   1. Application source archive metadata (none - Git-free app subtree).
   2. Upstream Flutter SDK metadata (.git, .pub-preload-cache) - shipped.
   3. Generated Flutter SDK cache artifacts (bin\cache generated during
      snapshot regeneration - category B/C in the diff closure).
   4. The intentional VS2026 source patch (single file, category A).
